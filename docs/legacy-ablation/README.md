# Historical documentation and ablation index

> **For the thesis writing agent:** Start with the [current guides](../01_training.md), the live implementation, and the resolved config for the experiment you are describing. Consult this archive only when those sources leave a specific term, design decision, or historical comparison unexplained.

These documents describe earlier revisions, removed implementations, proposed work, or live options under older configurations. Some commands, paths and examples refer to their original revision. Links to missing ablation files or removed levels may require the historical branch or the original source snapshot. Use a run’s source snapshot and frozen config to establish what actually ran. `final-ablation-archive` is the branch designated for historical ablation implementations. This archive preserves search terms and design context.
