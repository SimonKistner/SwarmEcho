# Archived target-location implementation

This is the previous multi-map suite implementation/configuration, retained for
historical plans and refits. It is not the active composition API. The reusable
rollout, reports and diagnostics are shared rather than copied into probe folders.

The family and its three subprobe definitions live in `../../probes/target_location/`.
Only shared coordinates has been migrated to the new shared execution pipeline.
See [the architecture](../../CONCEPT.md) and [archive overview](../README.md).
